# Incident

1. **Stabiliseren:** beperk de schade (markt pauzeren, opnames blokkeren via gate of beperking). Nooit data wissen.
2. **Melden:** dienstdoende eigenaar, en bij geld of persoonsgegevens direct de producteigenaar. Leg tijdstippen vast.
3. **Onderzoeken:** auditlog, journaal, operaties, workerlogs (gestructureerd JSON, zonder tokens of rekeningnummers).
4. **Herstellen:** alleen via normale routes met vier ogen (correctieboeking, goedkeuringen). Ingrepen die dat niet kunnen, als gedocumenteerde migratie met review.
5. **Communiceren:** betrokken klanten via support; bij een datalek de wettelijke meldplicht beoordelen.
6. **Nazorg:** oorzaak, test die het voortaan vangt, draaiboek bijwerken, besluit in `docs/12-decisions.md` als een regel verandert.
